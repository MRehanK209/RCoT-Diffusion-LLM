\section{Limitations}
The draft has several limitations. First, parser dependence is unavoidable: GSM8K requires boxed answers in the main evaluator, Countdown requires a chained-equation format, and Trip Planning requires parseable itinerary lines. Different parsers could change absolute scores. Second, GSM8K is partly saturated, so it is more useful for prompt sensitivity than for paradigm ranking. Third, inference systems differ: diffusion pass@k uses fast-dLLM and autoregressive pass@k uses vLLM, so speed comparisons are backend-dependent. Fourth, sample counts differ by benchmark: 128 samples are available for GSM8K and Countdown, while Trip Planning uses 64 samples. Fifth, the comparison is limited to 7B--8B checkpoints and does not test larger model scales. Finally, the ensemble interpretation is supported by correlations but has not yet been validated by an explicit ensemble experiment.
