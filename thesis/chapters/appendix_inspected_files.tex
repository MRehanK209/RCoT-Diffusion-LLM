\section{Inspected Files and Legacy Parser Notes}
The main parser and scoring behavior described in Section~\ref{sec:parser-details} comes from \texttt{\detokenize{inference_and_generation.py}}, \texttt{\detokenize{dataset/gsm8k.py}}, \texttt{\detokenize{dataset/countdown.py}}, \texttt{\detokenize{dataset/trip_planning.py}}, \texttt{\detokenize{metrics/parsers.py}}, \texttt{\detokenize{metrics/pass_k.py}}, and \texttt{\detokenize{evaluate_pass_k.py}}. Legacy helper code in \texttt{\detokenize{utils.py}}, \texttt{\detokenize{metrics/parse_and_get_acc.py}}, and \texttt{\detokenize{metrics/parser_json.py}} contains alternative boxed-answer, arbitrary-expression, and JSON-style parsers, but those helpers are not the source of the main Milestone 2 pass@k result JSONs.
