\section{Inspected Files and Legacy Parser Notes}
\label{sec:appendix-inspected-files}
The main parser and scoring behavior described in Section~\ref{sec:parser-details} comes from the following files. GSM8K extraction: \texttt{\detokenize{dataset/gsm8k.py}}, \texttt{\detokenize{metrics/parsers.py}}, \texttt{\detokenize{inference_and_generation.py}}, \texttt{\detokenize{evaluate_pass_k.py}}. Countdown-cd4 scoring: \texttt{\detokenize{dataset/countdown.py}}, \texttt{\detokenize{inference_and_generation.py}}, \texttt{\detokenize{evaluate_pass_k.py}}. Trip Planning scoring: \texttt{\detokenize{dataset/trip_planning.py}}, \texttt{\detokenize{inference_and_generation.py}}, \texttt{\detokenize{evaluate_pass_k.py}}. Pass@k computation is shared via \texttt{\detokenize{metrics/pass_k.py}}.

Legacy helper code in \texttt{\detokenize{utils.py}}, \texttt{\detokenize{metrics/parse_and_get_acc.py}}, and \texttt{\detokenize{metrics/parser_json.py}} contains alternative boxed-answer, arbitrary-expression, and JSON-style parsers, but those helpers are not the source of the main pass@k result JSONs analyzed in this thesis.
